등록은 이렇게 해요

  1. 3가지 철칙을 확인해요 — 잔액 캐시 금지, 자체 화폐 금지, 숫자 하드코딩 금지. 유지 조건이에요.
  2. 레지스트리에 항목을 추가해요 — registry/modules.json에 이름·유형·소개·링크를 넣어요.
  3. PR을 보내요 — npm run validate:registry가 통과하면 운영자가 확인해서 병합해요. 병합되면 이 페이지에 바로 반영돼요.
